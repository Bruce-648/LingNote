# LingNote 0.3.0 使用说明

适用于 Windows 11 x64。安装包自带程序运行库；语音识别模型在安装后自行下载。

## 开始使用

1. 运行 LingNote-0.3.0-Setup.exe 完成安装，从开始菜单或桌面打开 LingNote。
2. 点击「设置」顶部的「下载模型」，下载 Whisper small 语音模型（约 466 MB）。界面会显示下载进度，也可取消后重试。下载完成会校验文件，之后可离线转写。如果下载服务暂时无法连接，可从模型官方来源下载 ggml-small.bin，再使用「导入模型」。
3. 在设置中填写自己使用的 AI 服务接口地址、模型名称和 API Key，测试连接并保存。接口需支持兼容 OpenAI 的 Chat Completions 文本请求。
4. 在浏览器中播放网课，点击「开始录音」。录制的是系统默认播放设备的声音，不是麦克风。
5. 切换到视频窗口或最小化时，可用悬浮条暂停、继续、结束或返回主窗口。
6. 结束录音后等待转写与笔记整理。笔记可复制、编辑并导出 Markdown，也可以单独查看原始转写和回放录音片段。

处理上一段录音时，仍可收起或展开「主题」「未分区」及自定义分区，也可点击「新录音」开始下一段；结束后会独立排队整理。
笔记正文可直接点击编辑并自动保存，转写页保持只读。
需要重新生成时，点击笔记页右上方的「重新整理笔记」。失败时保留原笔记，成功后原笔记存入历史版本，可从课程操作菜单恢复。

无需 API Key 也能先录音并本地转写；配置接口后可继续整理。AI 请求由使用者自己的 API 账户计费。

## 管理记录

「主题」「未分区」和自定义分区在侧栏同级显示。通过「未分区」右侧的三个点新建分区。
录音可以移动到主题或分区，整个主题也可以移动到分区。
「移除分区」保留内容并移回默认区域。「删除录音」会在确认后删除分区内的录音与笔记，包括主题里的录音。

## 数据保存

安装版默认在当前 Windows 用户的 `%LOCALAPPDATA%\LingNote` 目录保存录音、笔记和设置，与程序安装目录分开。
设置中的「打开数据文件夹」可以找到实际目录。升级时请保留数据文件夹；换电脑时先导出笔记并备份整个数据文件夹。
API Key 使用 Windows 当前用户加密，换用户或换电脑后应重新填写自己的 Key。

## 双版本笔记

结束录音后，默认以单栏生成「课堂笔记」。用户点击工具栏「精编笔记」后才展开双栏，并依据课堂笔记生成右侧「精编笔记」。课堂笔记忠于录音并清理旁白、重复提醒和无关操作说明；精编笔记围绕识别出的主题重新组织，可补充课堂笔记中未出现的主题核心知识；基础事实简写，重要机制和适用条件写完整；整篇选择 0–2 个必要例子，可以由 AI 自拟。正文只写知识，不写课程叙述或整理说明。
两栏可分别直接编辑、复制与导出。右侧「重新精编」仅更新精编笔记，并保留上一版；左侧「重新整理笔记」更新课堂笔记后，可再点击右侧重新精编。
旧录音仍保留原笔记，点击右侧「生成精编笔记」即可补出第二版。第二阶段失败保留已生成的课堂笔记，可单独重试右侧；精编功能使用设置中的 AI 接口，会产生额外请求。不同录音的精编任务可同时进行，切换记录不影响后台任务。

原音频和语音识别在本机处理。生成笔记时，转写文字会发送给你配置的 AI 服务。
系统播放设备的提示音和其他音频也可能被录入；课程中的术语、数字等请结合原始转写和录音核对。

精编任务由独立后台进程执行，各条记录可同时运行。精编笔记以主题知识为主线，按需增补缺失的核心知识、删减、纠错并调整结构，目标是准确清晰，篇幅可能缩短。

课堂笔记与精编笔记都以复习和快速查阅为目标。去重、组织结构与详略选择直接在生成时完成，单段输入只请求一次；超出设置的处理长度时分段生成，并合并多段结果，超长稿按主题分批合并。

精编长笔记时最多两段并行请求；界面显示实时草稿，完成后才保存正式结果。若接口不返回流式内容，则在分段完成后显示草稿。不再固定追加一次成稿校订，实际等待时间取决于输入长度和 AI 服务速度。

性能诊断记录保存在数据文件夹的 diagnostics 目录，包含耗时和数量，不包含笔记正文、标题或 API Key。录音结束时的待转写片段数与等待时间可用于判断是否存在转写积压。

AI 接口使用 OpenAI 兼容的 Chat Completions 格式。在「设置 → AI 设置」中填写服务提供商的兼容接口地址、模型和对应密钥。DeepSeek、OpenAI、Gemini 的兼容地址及通义千问的 DashScope 兼容地址可以自动识别思考参数；其他兼容服务使用现有兼容设置；无法自动识别时使用服务默认值。

不同模型支持的思考强度各不相同，通义开关协议只提供 Off 和 On；仅支持思考的模型无法关闭思考。若接口返回参数不支持，请核对该模型的官方文档，并确认该服务和模型支持相应参数。Gemini 使用 `https://generativelanguage.googleapis.com/v1beta/openai/` 等兼容地址；原生专有协议（如 Anthropic Messages）不在本版本的接口范围内。关闭思考可能更快，也可能影响复杂笔记质量。

双栏笔记中，拖动两栏之间的竖向手柄可调整左右宽度。

精编使用 AI 的基础知识补全主题，程序不自动检索教材或独立核验事实；专用定义、版本事实及重要结论应结合可信资料核对。

## 录音结束后的笔记模式

在「设置 → AI 设置 → 笔记模式」选择：默认先生成课堂笔记，用户需要时再精编；也可选择「精编模式」，录音后生成精编笔记，转写作为主题和范围线索，结果按主题组织并可补齐核心知识。选择对之后开始的新录音生效，每条录音保留自己的模式。精编模式仍保存录音与转写；失败可重试，重新精编会保留上一版。

精编模式中的补充来自模型知识，程序不会自动检索教材；关键事实仍需核对。
