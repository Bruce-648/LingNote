# LingNote 0.1.33 使用说明

适用于 Windows 11 x64。安装包自带程序运行库；语音识别模型在安装后自行下载。

## 开始使用

1. 运行 LingNote-0.1.33-Setup.exe 完成安装，从开始菜单或桌面打开 LingNote。
2. 点击「设置」顶部的「下载模型」，下载 Whisper small 语音模型（约 466 MB）。界面会显示下载进度，也可取消后重试。下载完成会校验文件，之后可离线转写。如果下载服务暂时无法连接，可从模型官方来源下载 ggml-small.bin，再使用「导入模型」。
3. 在设置中填写自己使用的 AI 服务接口地址、模型名称和 API Key，测试连接并保存。接口需支持兼容 OpenAI 的 Chat Completions 文本请求。
4. 在浏览器中播放网课，点击「开始录音」。录制的是系统默认播放设备的声音，不是麦克风。
5. 切换到视频窗口或最小化时，可用悬浮条暂停、继续、结束或返回主窗口。
6. 结束录音后等待转写与笔记整理。笔记可复制、编辑并导出 Markdown，也可以单独查看原始转写和回放录音片段。

无需 API Key 也能先录音并本地转写；配置接口后可继续整理。AI 请求由使用者自己的 API 账户计费。

## 管理记录

「主题」「未分区」和自定义分区在侧栏同级显示。通过「未分区」右侧的三个点新建分区。
录音可以移动到主题或分区，整个主题也可以移动到分区。
「移除分区」保留内容并移回默认区域。「删除录音」会在确认后删除分区内的录音与笔记，包括主题里的录音。

## 数据保存

安装版默认在当前 Windows 用户的 `%LOCALAPPDATA%\LingNote` 目录保存录音、笔记和设置，与程序安装目录分开。
设置中的「打开数据文件夹」可以找到实际目录。升级时请保留数据文件夹；换电脑时先导出笔记并备份整个数据文件夹。
API Key 使用 Windows 当前用户加密，换用户或换电脑后应重新填写自己的 Key。

原音频和语音识别在本机处理。生成笔记时，转写文字会发送给你配置的 AI 服务。
系统播放设备的提示音和其他音频也可能被录入；课程中的术语、数字等请结合原始转写和录音核对。
