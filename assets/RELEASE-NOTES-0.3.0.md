# LingNote 0.3.0

- 设置页使用独立导航替换主侧栏，默认选中常规，支持搜索、返回状态恢复及后台任务不中断。
- 新增12种强调色、6种浅色背景，支持即时生效、自动保存及恢复默认。
- 设置图标使用透明生图素材，统一显示线宽、灰度和光学范围，保留自然比例。
- 悬浮条新增窗口截屏与区域截屏，支持快捷键、默认 download 目录和按主题指定目录。
- 创建主题支持可选截屏文件夹，菜单统一为现代圆角样式。
- 录音列表新增批量选择与删除，支持折叠项全选、数量确认、任务保护，并保留主题和分区。
- 保留系统录音、本地转写、课堂/精编笔记、编辑导出、模型导入和应用更新功能。
- 程序、安装包、版本徽章和使用文档统一为0.3.0；本地仅保留当前发布版。

安装包不包含个人录音、笔记、API密钥或语音模型。原有数据目录、模型及数据备份保留。
