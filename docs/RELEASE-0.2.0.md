# LingNote 0.2.0 本地交付

当前仅保留一个发布版本：**0.2.0**。

## 常用入口

- `LingNote.lnk`：现有启动快捷方式，仍指向 `app/LingNote.exe`。
- `app/`：0.2.0 自包含 Windows 应用，含运行依赖。
- `artifacts/0.2.0/LingNote-0.2.0-Setup.exe`：最新安装包。
- `artifacts/0.2.0/LingNote-0.2.0-Setup.exe.sha256`：安装包 SHA-256 校验文件。
- `assets/RELEASE-NOTES-0.2.0.md`：当前更新说明。

## 目录保留范围

| 目录/文件 | 用途 |
|---|---|
| src、tests、tools | 当前源码、自动化检查、打包工具 |
| app | 当前可运行程序及必需依赖 |
| Data | 原有录音、笔记、设置、模型与数据备份，完整保留 |
| library-location.json、LingNote.lnk | 原有数据绑定与快捷方式，完整保留 |
| assets | 当前资源、许可文件、使用指南、语音模型及构建依赖 |
| docs | 开发文档、笔记提示词文档、本交付说明 |
| .git、.packages | 版本库及本地构建依赖缓存，保留 |
| artifacts/0.2.0 | 当前安装包、截图、测试日志、清理清单、数据核验结果 |

## 已清理

删除 0.1.33–0.1.49 安装包及校验文件、旧版本更新说明、过时的 UI 设计包和图标 PNG、旧截图/日志/评估输出、重复发布目录及 src/tests 的 bin/obj 临时构建目录。

共清理 199 个目标、3,334 个文件，释放 1,992,210,642 字节（约 2 GB）。未清理用户 Data 内的历史备份。

## 验证

- Release 自包含发布及 Inno Setup 安装包生成成功。
- 应用程序集版本：0.2.0.0；安装包产品版本：0.2.0。
- 安装包 SHA-256 与校验文件一致。
- 96 项业务回归、98 项 UI 回归、12 项设计检查通过。
- 162 个受保护文件在清理前后逐一进行 SHA-256 比较，全部一致；无文件丢失。
- SQLite integrity_check：ok；原有课程记录共 4 条。
- 详细结果见 artifacts/0.2.0 中的日志与 JSON 清单。

截图为隔离数据下的真实 WPF 界面渲染。AI 回归使用本机模拟服务；没有为本次整理调用真实付费 AI 接口或执行完整模型转写。此版本按用户要求使用紧凑布局，右栏名称为“精编笔记”，文件夹与设置齿轮为清晰的透明底矢量绘制，高级设置不展示“思考参数协议”。

bin/obj 已清理，下次从源码构建请先恢复依赖，或直接运行 tools/build.ps1（不加 SkipRestore）。运行 app/LingNote.exe 不需要恢复依赖。
