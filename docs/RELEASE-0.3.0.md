# LingNote 0.3.0 本地交付

当前仅保留一个发布版本：**0.3.0**。

- 原快捷方式 `LingNote.lnk` 继续指向 `app/LingNote.exe`。
- 当前程序程序集版本为 `0.3.0.0`，安装包产品版本为 `0.3.0`。
- 安装包：`artifacts/0.3.0/LingNote-0.3.0-Setup.exe`；旁边保留 SHA-256 校验文件。
- 设置重构、窗口/区域截图、12种强调色与6种背景、透明生图图标、主题目录与批量删除均包含在当前版本。

## 整理结果

删除旧0.2.0安装包、重复发布目录、旧截图日志及src/tests的bin/obj，共27个目标、2,132个文件，释放852,417,362字节（约813 MiB）。

保留 `Data` 全部录音、笔记、设置、模型和历史数据备份，以及 `download`、数据绑定、原快捷方式、源码、测试、资源、工具、Git仓库和离线依赖缓存。

当前文档和截图位于 `docs/`，生图提示词归档到 `docs/ui-assets/`。本次验证日志和清理清单位于 `artifacts/0.3.0/validation/`。

## 验证

- 96项业务回归、101项UI回归、40项设置专项和22项批量删除专项通过。
- 170个受保护文件清理前后SHA-256完全一致，没有丢失或改动。
- SQLite完整性检查通过，数据绑定保持原库。
- 当前安装包SHA-256与校验文件一致；没有在网上发布版本。

临时构建目录已移除，后续源码构建需先恢复依赖，或运行不带`-SkipRestore`的`tools/build.ps1`。直接运行`app/LingNote.exe`无需恢复依赖。
