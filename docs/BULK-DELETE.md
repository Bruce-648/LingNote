# 录音批量删除

使用：鼠标移至“未分区”、某个主题或自定义分区标题，打开旁边的“…”菜单，选择“批量选择”。勾选录音后使用左侧底部的全选、删除、取消按钮；Esc 可退出。

- 全选只覆盖进入模式时的列表范围，包含“展开显示”及折叠主题内的隐藏记录。
- 录音中及后台处理中的记录禁选；删除确认后会再次检查任务状态，期间启动处理的记录会跳过。
- 删除前明确显示数量、范围及笔记、转写、音频的删除说明。取消保留勾选及全部数据。
- 批量数据库删除在同一事务中写入删除墓碑并清除记录；延迟保存不会恢复已删记录。音频目录使用原有安全路径校验与清理逻辑。
- 主题、分区及展开状态保留；删除其他记录不切走当前笔记，删除当前笔记后恢复新录音界面。原有文件占用时的音频目录清理限制保持不变。

实现文件：MainWindow.Bulk.cs、MainWindow.xaml、MainWindow.xaml.cs、MainWindow.Sections.cs、MainWindow.Design.cs、Store.cs、UiIcons.cs。

验证：独立测试库中的22项批量删除专项、96项业务回归及101项UI回归通过。专项覆盖确认/取消、隐藏项、任务状态变化、主题与分区范围、录音文件清理、删除墓碑及界面状态保留。没有对用户现有录音执行删除。

程序：E:\LingNote\app\LingNote.exe
安装包：E:\LingNote\artifacts\0.3.0\LingNote-0.3.0-Setup.exe
