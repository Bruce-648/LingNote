**LingNote** 是一款轻量的 Windows 桌面录音与 AI 笔记工具。录下电脑播放的声音，在本地用 Whisper 转写，再通过你配置的 AI 接口生成可编辑、复制和导出的笔记。

适合整理线上课程、讲座、会议回顾、访谈、播客和直播。当前源码版本为 **0.3.0**，界面以简体中文为主。

## 功能特性

- **系统录音**：支持暂停、继续和结束；录音期间仍可浏览历史笔记。
- **独立悬浮控制**：切换窗口或最小化后继续控制录音，支持置顶、拖动，以及收起为幽灵悬浮球。
- **本地语音转写**：使用 Whisper small 多语言模型，模型准备好后可离线转写，保留原始转写文本与时间戳。
- **课堂笔记与精编笔记**：双栏对照阅读，各自编辑、自动保存、复制和导出；支持单独重新整理、重新精编及历史版本恢复。
- **按主题管理**：主题支持文件夹式展开、收起；记录可按主题、未分区和自定义分区组织。
- **窗口与区域截屏**：悬浮条提供截屏按钮和模式菜单，支持全局快捷键；主题可单独指定保存文件夹。
- **录音批量删除**：按未分区、主题或分区勾选记录，全选包含折叠项；删除前确认数量，录音中和处理中的记录受到保护。
- **分类设置与配色**：进入设置时，设置导航完整替换主侧栏，默认选中常规；支持搜索及返回状态恢复。提供 12 种强调色和 6 种浅色背景，即时生效并自动保存。
- **可配置的 AI 连接**：填写接口地址、模型与 API Key，支持连接测试、请求超时和 SSE 流式输出；在常规设置中调整笔记模式、思考强度及每段整理字数。
- **回放、导出与更新**：回放录音片段、导出 Markdown，并通过应用内入口检查更新。

## 快速开始

1. 从 **[Releases](https://github.com/Bruce-648/LingNote/releases)** 获取已发布的安装包。已有本地构建时，可使用 `artifacts/0.3.0/LingNote-0.3.0-Setup.exe`，或直接运行 `app/LingNote.exe`。
2. 打开 **设置 → 本地语音模型**，下载或导入 Whisper small 多语言模型，约 **466 MB**。安装包不包含模型，只需准备一次。
3. 在 **设置 → AI 连接** 中填写兼容 OpenAI Chat Completions 的接口地址、模型名称和 API Key，点击「保存」与「测试连接」。
4. 播放需要记录的内容，点击「新录音」，再点击「开始录音」。
5. 点击「结束并整理」，等待转写与笔记生成，再阅读、编辑或导出结果。

支持 **Windows 11 x64**。安装包包含 .NET 运行依赖，普通使用无需安装 .NET SDK。录音和本地转写不需要 API Key；AI 整理需要网络与相应的服务配置，费用由你使用的 AI 服务决定。

## 两种笔记模式

在 **设置 → 常规 → 笔记模式** 中选择。修改只影响之后开始的新录音，每条记录保留自己的模式。

| 模式 | 录音结束后的行为 |
| --- | --- |
| 课堂模式（默认） | 先生成课堂笔记，在双栏右侧按需生成精编笔记。 |
| 精编模式 | 直接依据转写生成精编笔记，以单栏展示，同时保留录音与原始转写。 |

**课堂笔记**根据录音内容整理，去除重复和无关叙述。**精编笔记**以主题知识为中心独立组织，按需补齐主题内缺少的核心知识，并非逐句复述录音；篇幅也可能缩短。精编会调用配置的 AI 接口。

笔记正文可直接编辑并自动保存，原始转写页为只读。双栏宽度可拖动调整，两栏独立滚动；重新整理或精编成功后保留上一版，失败时保留原有内容。

## 截屏与保存位置

点击悬浮条上的截屏按钮可截取窗口，通过旁边的下拉菜单切换到区域截屏。应用运行时也可使用快捷键：

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + Shift + 1` | 截取前台窗口 |
| `Ctrl + Shift + 2` | 拖动选择截屏区域 |
| `Esc` | 取消区域选择 |

图片以 PNG 格式保存，截取前会隐藏悬浮条。快捷键被其他程序占用时，可使用悬浮条按钮。

保存位置按以下顺序决定：

1. 当前录音或笔记所属主题的自定义文件夹。
2. **设置 → 存储与数据** 中选择的默认截屏文件夹。
3. 应用或项目目录下的 `download` 文件夹，路径随安装位置自动确定。

创建主题时可以选择截屏文件夹，也可以留空。之后可从主题菜单更改文件夹或恢复默认目录。截图保存于本地，不会作为笔记附件自动发送给 AI。

## 批量管理录音

1. 将鼠标移到“未分区”、主题或自定义分区标题上，点击旁边的 **··· → 批量选择**。
2. 勾选要删除的录音，或使用左侧底部的 **全选**。全选仅限当前范围，但包含折叠和“展开显示”内的记录；分区范围包括其中主题内的录音。
3. 点击 **删除**，核对数量及提示后确认。也可点击 **取消** 或按 `Esc` 退出批量模式。

删除会移除所选记录及其笔记、转写和音频，**无法撤销**；主题、分区和原有展开状态会保留。正在录音或后台处理的记录不可选，确认删除时也会再次检查任务状态。

## 设置与外观

设置导航与主导航在同一位置切换，始终只有一个侧栏。进入时默认选中 **常规**，返回后保留原来的笔记和列表状态；切换设置不会停止录音或后台处理。

| 分类 | 内容 |
| --- | --- |
| 常规 | 笔记模式、思考模式、每段整理字数 |
| AI 连接 | 接口地址、模型、API Key、连接测试、请求超时与流式输出 |
| 本地语音模型 | 下载或导入 Whisper small 模型 |
| 应用更新 | 当前版本、检查更新、启动时自动检查更新 |
| 存储与数据 | 打开数据目录、设置默认截屏文件夹 |
| 快捷键 | 截屏快捷键说明 |
| 外观 | 12 种强调色、6 种浅色背景及恢复默认配色 |
| 关于 | 应用介绍与实际版本号 |

配色选择立即应用并自动保存，重新打开应用时恢复。卡片保持白色，以便阅读。

## 使用说明

- 录制的是**系统默认播放设备的声音**，不直接采集麦克风，也不录制屏幕视频；截屏功能单独保存静态图片。线上会议中你自己的麦克风发言可能不会被录入；其他应用播放的声音也可能被录入。
- 切换窗口或最小化后可使用悬浮控制，结束录音会返回主窗口。关闭主窗口会隐藏到托盘，从托盘菜单可以重新打开或退出。
- 处理上一段录音时可以开始下一段；录音与处理结果分别保存。
- 处理失败时录音仍保留。检查模型或 AI 配置后，可用笔记栏中的继续整理、重新整理或重新精编按钮重试。
- 思考模式的可选项取决于接口和模型；不支持的模型会禁用该设置。

## 数据与隐私

音频、转写、笔记和设置保存在本地。安装版默认数据目录为 `%LOCALAPPDATA%\LingNote`；使用已有数据绑定时，程序会继续使用绑定目录。通过 **设置 → 存储与数据 → 打开数据文件夹** 查看实际位置，升级或迁移时请保留并备份该目录。

语音转写在本机执行。AI 整理和精编会将相应的转写、笔记及相关文本上下文发送给你配置的服务。API Key 使用 Windows 当前用户的 **DPAPI** 加密保存，换电脑或 Windows 用户后需要重新填写。

语音识别和 AI 输出可能存在错误。精编内容来自模型知识，程序不会自动检索教材或独立核验事实；重要术语、数字、定义和结论请结合录音及可信资料核对。Markdown 支持表格、列表、代码与常见公式的可读显示，复杂 LaTeX 暂无完整排版支持。

## 开发与项目结构

技术栈：**C# / WPF / .NET 10**，配合 NAudio、Whisper.net、Microsoft.Data.Sqlite 和 Markdig。

```text
LingNote/
├─ src/LingNote/          # 应用源码、图标与字体
├─ tests/LingNote.Tests/  # 自动化检查
├─ assets/               # 资源、许可、模型信息与更新说明
├─ docs/                 # 文档与界面截图
├─ tools/                # 构建与安装脚本
├─ Data/                 # 已绑定的本地录音库（不提交）
├─ download/             # 默认截屏输出目录
├─ app/                  # 本地可运行程序（不提交）
└─ artifacts/0.3.0/       # 当前安装包与验证记录（不提交）
```

源码运行、依赖恢复、测试及打包步骤见 **[开发文档](docs/DEVELOPMENT.md)**。本地交付与验证结果见 **[0.3.0 交付说明](docs/RELEASE-0.3.0.md)**，版本变化见 **[更新说明](assets/RELEASE-NOTES-0.3.0.md)**。批量删除的详细说明见 **[批量管理文档](docs/BULK-DELETE.md)**。
